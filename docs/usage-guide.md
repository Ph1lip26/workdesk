# Workdesk 使用指南

本页以 Windows 0.2.7 的功能为基线，2026-11-13 整理。版本交付与历史验证见 [CHANGELOG](../CHANGELOG.md)，下载见 [README](../README.md#下载-windows-安装包)。本文不是一次新的运行验收；Mac 边界见 [Mac 测试版](mac-preview.md)。

## 1. 安装与首次配置

1. 从本仓库 Releases 的 Assets 下载 `Workdesk-Setup-版本-x64.exe`，核对同版本 SHA256。程序未签名，系统可能提示未知发布者；不要关闭系统防护来掩盖来源问题。
2. 安装并启动，选择自己的知识库、Codex 和 Obsidian 路径。外部程序需要自行安装，Codex 需有效登录，Obsidian CLI 需启用。
3. 知识库需有 `原始资料/`、`处理文件/`；归类候选来自现有主题 `_索引.md`，软件不擅自创建新主题。
4. 需要收藏采集时，再主动打开专用抖音窗口扫码。有效登录后普通刷新在后台进行；不会接管日常浏览器登录资料。
5. 首次处理视频会联网下载解码组件和转写模型，需留出空间。图文不要求语音解码组件。AI 使用自己账户可用的 Codex 额度，不要求预填 API Key，也不附带会员。

程序带独立 Python、Chromium 和主要 ASR 依赖，不要求复制开发者环境或安装旧版知识库 Skill。可选 GPU 配置见本页后文。

## 2. 导航、主题与窗口

- 点击一级功能图标进入该模块并展开二级导航；再次点击当前图标收起／展开。首页没有二级导航，底部不另放收展按钮。
- 按住一级图标约 **250ms**，出现预览后拖到另一个图标交换位置。首页、抖音、购买、健康可排序，Logo 与设置固定；取消或保存失败回退。顺序只存本机。
- 二级栏与一级轨相连，显示当前模块的子页面／事项；关闭后不留不可见键盘焦点。购买事项标题在二级栏，处理队列在主页面，不是弹窗。
- 外观支持黑夜、白昼、跟随系统；显式选择日夜时不受系统主题变化影响。设置仅影响本应用，不修改 Windows 系统设置。封面图不反色。
- 导航动效可跟随系统、显式采用适度动效或关闭；快速反向接续当前可见状态。减弱动效时仍有明确文字与状态反馈。
- 默认窗口 1180×760，最小 800×560。首页以六卡、精炼、一屏为常规目标；同时很窄且很矮时允许两列滚动，不以无限缩字保证形式上的一屏。
- 关闭窗口收进托盘，后台任务继续；彻底退出需空闲。重载界面与重启后台不同，都应先保存购买、体重或生病编辑，不强制中止任务。

## 3. 首页与刷新

六类卡片：**当前状态、近期安排、抖音收藏、本地素材、购买决策、个人健康**。模块卡片可跳转到相应功能，来源和图表有独立交互；没有个人来源时显示真实空状态或已有模块，不用虚构记录填充。

右上拖动柄调整卡片顺序；键盘可用空格／Enter拾取、方向键移动、Enter保存、Esc取消。保存失败提示并回退，后台刷新不覆盖用户顺序。顶部不放日期时钟，测量或来源日期仍保留。

首页个人来源由私有 `homepage.json` 绑定到知识库相对路径及章节，不扫描整库。来源移位或不可读会报错，不猜替代文件。摘要区只显示短概括；原文、证据和详细记录从来源入口查看。

### 三种“刷新”不要混用

| 操作 | 行为 | Codex 额度 |
|---|---|---|
| 刷新收藏 | 后台读取抖音，显示阶段、数量、耗时和结果；失败保留旧收藏 | 不使用 |
| 首页“更新摘要”／购买页“更新知识库摘要” | 根据明确绑定或关联的资料生成简短摘要与引用 | 使用；资料、日期窗口、手动记录及格式未变时复用缓存 |
| 体重页“刷新” | 从绑定笔记解析明确测量记录并增量同步 | 不使用 |

**启动、恢复、获得焦点不会自动全量同步收藏或调用模型。** 页面读取缓存、轮询本地任务状态不是新采集。生成摘要遇到忙碌、额度或证据错误时保留旧结果，不自动重试；不要用反复重启代替查看提示。

摘要区分记录与 AI 建议，不把过期计划顺延，不把价格／发布日期猜测写成事实。引用核验只确认文字出处，不代表作者主张已联网验证。购买摘要不会覆盖手动字段。

## 4. 抖音收藏与本地素材

### 选择与入库

- 默认显示 **未入库**，最近收藏在前；这不是作品发布时间排序。支持全部／已入库筛选、收藏夹、搜索及可选发布顺序。
- 每页 30 条，筛选针对当前完整范围；跨页保留勾选。标题打开本地详情，原作品通过独立入口打开。
- 每批最多选 20 条入库，统一应用内确认后开始。已存在资料不重复保存，分类不明确时等待选择。
- **已入库 = 有知识笔记或原始资料。** 只有原始资料不等于已完成知识笔记，仍可继续生成；已有知识笔记可参与行动建议而不重复入库。
- 本地素材数量是内容记录数，并非当前下载文件数。清理中间媒体后记录与笔记仍可保留。

### 处理链路与范围

视频使用语音转写、抽样拼图和代表原帧联合分析；静态图文逐张识别原图及文案，不编造口播和时间戳。非口播视频不因 ASR 为空就视为无内容，证据不清时保留不确定性。

| 输入 | 当前边界 |
|---|---|
| 视频 | 超过 1 小时或转写超过 6 万字符暂停，不默默截断 |
| 静态图文 | 1–40 张 JPEG／PNG／WebP；每张 ≤25MB，合计 ≤100MB |
| 动态照片 | 静态画面可分析，运动部分未覆盖 |
| AI 证据 | 视频画面为抽样，不等于逐帧看完整条；图像／作者主张不自动成为已验证事实 |

完整转写和抽帧可复用；缺项才补。较长转写采用带行号、原文锚点的差量校对，本机还原全文，保留未修改行和时间戳；不以摘要替代全文或缩减知识笔记。

### 当前处理队列

二级导航中的名称仍为“处理队列”，主页面只显示排队、处理中、待归类、失败、取消等未成功结束任务；完成／已存在记录不展示，但历史未删除。

队列串行；暂停不立即杀掉当前阶段，取消在安全边界生效。**单条模型内容校验失败**时只保留该条失败任务和素材，继续下一条；共享解码组件、Codex服务／登录／额度故障仍暂停整队，避免同源故障连续失败。失败项需用户明确重试，不自动付费或换模型。流动条表示处理中，不是假百分比。关闭窗口不会取消已提交任务。本段是2026-11-16本机修复的行为，公开0.2.7安装包尚未包含。

### 入库后素材回收

0.2.7 包含成功入库后的安全回收：先核对笔记、原始资料、来源 ID、索引、日志、哈希及引用，再清理该任务未被引用的中间视频、抽帧和拼图。原图仅在知识库完整副本已嵌入且哈希一致时清理重复缓存。

失败／运行／排队／待归类／取消任务、被引用的库外素材、未知文件、转写、元数据、模型、账号与个人记录不删。路径异常、内容变化或被占用则保留。清理异常不把成功入库改成失败；任务目录 `cleanup.json` 留存结果与已删除文件的逻辑体积。

没有启动扫描、监控或定时清理，不自动批量删除历史缓存。

### 收藏转行动

选择 1–8 篇已有知识笔记，点击“收藏转行动”，填写要解决的问题后主动生成最多三个候选。只有原始资料的条目不冒充知识笔记，资料过长会要求减少选择，不静默截断。

生成消耗 Codex 额度，附来源引文、适用理由、第一步、最小成果、投入粗估及待确认项。可标记想做／先储备／不考虑，复制上下文继续讨论，回看最近 40 批；查看历史不调用模型。标记不自动启动项目、排期或执行；原笔记不改写。中断后由用户手动重试，不自动争用入库任务额度。

## 5. 购买决策夹

二级导航选择事项，主区显示完整详情；支持搜索、状态筛选、新建、编辑和复制上下文。

- 记录需求、排除项、预算、候选、价格渠道及核价日期、结论归属、等待条件和回看日期。
- 区分用户决定、AI 建议与资料摘录；价格是历史记录，不是实时比价。回看日期不等于提醒，“已决定”不等于成交。
- 关联笔记使用准确知识库相对路径；“更新知识库摘要”读取资料，生成结论／等待条件／待核实点。手动内容保持原样，冲突单列。
- 复制上下文只复制，不自动发送或开始调研；公共首次启动为空，不预填私人购买需求。
- 未保存编辑有离开保护；保存失败保留填写，版本冲突不覆盖较新记录。

## 6. 个人健康

### 体重记录

手动填写测量日期与公斤／斤，保留历史、修改与确认删除。支持 30 天／90 天／全部趋势；同日多条全部保存，曲线取最后录入值，不补造缺失日期。不足两个测量日不连成曲线。

首页小图与健康主图均可就近悬停或轻点查看日期、公斤／斤，同时高亮点与参考线；支持左右方向键、Home／End和Esc。主图按内容宽度等比显示；不要求准确点中小圆点，不以录入时刻冒充测量时分，操作图表不误触整卡跳转。

点击刷新才同步知识库，打开页面不导入。来源为私有 `homepage.json` 的 `health_source`，未指定时用 `profile`。只识别该笔记表格中有明确日期、单位的实测值；不借用笔记维护日期，不导入目标、估计或模糊数值。

同日同值去重；同日不同值展示冲突并跳过，不覆盖手动记录；已删除导入项不被下一次刷新复活。来源不可读时保留已有记录，普通手动录入不依赖绑定。

### 生病记录

二级导航选“生病记录”。日期、症状必填，补充内容选填；可补记过去、同日多条、修改和确认删除。只存本机，不自动同步知识库或生成诊断。睡眠、运动与训练模块尚未交付。

## 7. 数据、迁移与更新

| 内容 | 保存位置与处理原则 |
|---|---|
| 程序文件 | 安装目录；更新可替换 |
| 配置、SQLite记录、登录、日志 | Windows 默认 `%APPDATA%\workdesk`；不进入仓库或公开包 |
| 下载、抽帧、模型、解码组件 | 本机私人区或用户指定的库外目录；占空间且有不同清理条件 |
| 笔记与原始资料 | 用户选择的知识库，按既有索引入库 |
| 私人品牌 | 私人数据目录 `brand/`；公开版本使用通用 W |

私人界面标识优先读取受限 `brand/mark.svg`，失败回退 `mark.png`，窗口／托盘读取 `icon.png`；只接受约束内的纯白路径或图片，禁止脚本、外链、越界路径等。私人标识不随公共源码和包发布，使用者负责确认权利。

更新前保存编辑、等待任务空闲、正常退出并备份。关闭窗口不等于彻底退出。卸载默认保留数据，但这不代替备份。新电脑安装不会自动迁移收藏、媒体、知识库或登录；旧迁移工具只复制队列数据库、保留源数据、不复制凭证，迁移后队列暂停，不应当成完整跨设备同步方案。

## 8. 排查失败

| 问题 | 首先查看 |
|---|---|
| 收藏刷新失败／不完整 | 连接详情与实际阶段，区分登录、网络、验证和页面变化；旧收藏应保留 |
| 处理命令退出码 1 | 对应任务日志，先分清下载、解码、ASR、模型、归类或写入，不仅凭代码猜原因 |
| 视频解码不可用 | `data/jobs/<任务ID>/components.log`；安装、权限、动态库都可能失败 |
| 体重或购买摘要未更新 | 来源绑定、关联路径、明确日期／单位、冲突或缓存提示；不同刷新按钮职责不同 |
| 笔记打不开 | Obsidian CLI是否启用、当前库和准确路径；不要建假文件修正状态 |
| Logo不一致 | 分别确认系统任务栏、桌面快捷方式、窗口／托盘、应用内导航；不要全局清缓存 |

解码器采用独立目录安装、验证后切换，失败保留旧入口及任务；修复后重试原任务，不反复清空素材。代码检查成功不代表网络、模型或平台限制以后不会变化。

### 可选 GPU 转写

语音默认 Whisper small、中文、beam_size=5、VAD。Windows 可配置 CUDA／float16，失败或超时回退 CPU／int8；已有完整转写复用，半成品不当作完整结果。

固定依赖见 `backend/requirements-asr-gpu.txt`，安装至私人目录并通过 `asr_cuda_path` 指定。DLL搜索路径只作用于 GPU 子进程，不改系统 PATH，不随安装包提供。`transcribe.log` 中尝试 CUDA 不等于成功，要看实际设备与完成记录。不要以单个合成测试推导每条视频都固定提速。

## 9. 能力边界

AI 内容会发送给 Codex 所连接的服务，不是全程离线。引用匹配不等于事实核查；视频抽样不等于完整审阅。复杂多收藏夹现场采集、另一台电脑的完整安装／卸载、Mac真机链路仍有验证空缺。

没有自动购物调研、实时比价、日历写回、目标编辑、睡眠／训练管理或跨设备自动同步。预留架构不代表功能已经实现。

### 备份和迁移范围

Windows 安装包只包含程序；不包含你的登录资料、知识笔记或本机记录。现有开发迁移工具以 SQLite Online Backup 复制整个工作台数据库，**不只是队列**：收藏关联、购买决策、健康记录、摘要等本机字段也可能被复制。应将迁移副本视为私密文件，不与程序安装包一起分享。素材、登录会话、私人外置文件与知识库不随数据库迁移，需各自核对；新机默认暂停队列。

程序版本、数据库副本、知识库原件各自核验。恢复前关闭并确认工作台空闲；目标已有数据时不要覆盖。可先恢复到隔离空目录，核对记录数量、布局顺序、能否打开笔记以及待处理草稿引用是否存在，再决定是否切换使用。
