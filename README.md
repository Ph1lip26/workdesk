# Workdesk

支持黑夜／白昼／跟随系统模式的个人工作台。当前源码包含个人首页、抖音收藏与购买决策夹；公开安装包版本仍以 Releases 为准，源码更新不等于已发布新安装包。

## 个人首页（源码修订，尚未发布安装包）

- 首页不使用二级导航，Windows 支持的窗口尺寸内六张卡片一屏可见，无需上下滚动；石墨卡片采用方向性高光、细边和克制阴影，与黑色页面分层。当前状态、近期安排、需要留意、抖音收藏、稍后计划和本地素材各有明确入口。
- 顶部不显示日期/时钟；记录的实际汇报日期仍保留。统一系统字体栈，在较大窗口区分标题、阶段、摘要与数字，短窗口保持可读字号。
- 首页列表只展示两项关键摘要，其余记录点「全部」查看；全文及来源仍可打开。窗口缩小或卡片换位时保持可读，不靠隐藏溢出裁掉按钮；小于桌面应用最小宽度的外部浏览器保留可读布局。
- 只读接入**明确选定的**知识库章节；不扫描整个知识库、不调用模型、不自动排期或标记完成。维护日期与实际汇报日期分别显示。
- 个性化绑定位于本机私人运行目录的 `homepage.json`，采用相对知识库路径；不放入源码、安装包或公开示例。未设置绑定时显示真实空状态，不使用假目标填充。
- 卡片可用右上拖动柄调整位置，顺序只保存在本机 SQLite 设置；重开仍保留，可恢复默认布局。键盘支持空格/Enter拾取、方向键移动、Enter保存、Esc取消；保存失败明确提示并回退。
- 当前支持来源约束的阶段、学科状态、计划与项目摘要；稍后计划只呈现明确暂缓的内容，不自动启动。编辑目标、记录完成、日历写回、健康打卡等尚未实现。
- 资料打开只接受配置中已选定的来源 ID，重新核验路径后通过 Obsidian 打开；文件移位或章节变化明确提示核对，不猜测替代资料。
- 首页和收藏切换保留分页、搜索与选择；机器处理队列不混入个人待办。
- 收藏侧栏移动时固定右边缘；列数变化将原卡片固定布局后交给合成器做单调位置／尺寸过渡，避免30张卡片逐帧重排，不使用网格快照或淡出刷新。官方视频/面板图标以五层 transform/opacity 同步交接；菜单文字在整个展开过程中逐渐显现，快速反向从当前状态接续，不循环播放。保留系统/本机适度/关闭动效设置。
- 换电脑时绑定文件可以由用户私下迁移，但不会随安装包同步；新知识库的文件和章节需重新核验。

当前 0.2.1：一体化标题区保留 Windows 原生窗口按钮；二级导航在窄窗口贴着图标轨滑出，不再模糊或遮罩整个页面。

## 购买决策夹（源码修订，未包含在0.2.1安装包）

一级图标轨的书签按钮进入购买决策夹；首页「稍后计划」卡片也有入口，显示未决定的事项数量。不增加第七张首页卡片、不改写已保存的卡片顺序。

购买事项标题统一放在二级导航；点选标题，右侧显示完整详情，不先打开编辑弹窗。二级导航保留搜索、状态筛选和新建，标题列表单独滚动，不再采用每页9项卡片总览。窄窗口仍是连在一级图标轨旁的面板，支持收展；键盘方向键／Home／End可选择事项。

- 新建／编辑购买事项，保存需求与排除项、预算、候选、当前结论、等待条件和可选回看日期；详情展示完整字段，不截断需求、候选或结论；顶部可显式编辑和复制上下文。
- 结论来源区分用户记录、AI建议、资料摘录。价格由用户填写，保留渠道与核价日期；不是实时价格，不自动爬取或补全。
- 「复制上下文」生成可核对的文本，点击复制后可粘贴到 Claudian；不启动模型、不自动发送、不要求API Key。
- 可关联已有知识库笔记，从已保存记录打开；不存在或越界的路径有明确错误，不自动创建或修复笔记。
- 购买内容保存在本机用户数据目录的SQLite；公共源码与安装包不包含个人购买事项。公共首次启动为空，不预填真实设备需求。
- 回看日期仅是记录，不代表提醒、新品发布日期或购买承诺。状态由用户修改，日期经过不自动推进；「已决定」不代表已成交。「暂不考虑」保留内容，可重新编辑。
- 未保存的编辑在关闭／Esc／点击外侧时要求明确放弃；保存失败保留填写，旧版本号不能覆盖已更新记录。

购买模块原生验证：`pwsh -NoProfile -File scripts/native_smoke.ps1 -Scope purchases`。仅用合成数据，不读真实购物记录。

## 自动刷新与外观（源码修订，未发布安装包）

- 默认窗口为1180×760，仍支持放大与800×560最小窗口；首页六卡继续一屏可见。
- 点击刷新立即显示状态；抖音刷新展示实际步骤、已读取数量、耗时与结果，未知完成比例不显示假百分比。使用轻量进度接口，不随进度重建作品／任务列表；本地刷新完成也显示耗时。
- 采集按真实分页响应继续，不再串联多段固定等待；已到末页不再额外滚动。不保证固定完成时长，未完整核验时仍保留旧收藏并标注范围。
- 启动、从托盘打开或从最小化恢复时，刷新首页来源、购买记录、本地素材与入库状态，同时静默刷新抖音收藏；同一次打开的多个窗口事件合并处理，普通切回窗口获得焦点不重复启动全量同步，已有登录检查／同步不会被重启。
- 刷新只更新数据，不重载页面、不创建AI任务；保留搜索、分页、勾选、卡片顺序和未保存编辑。同步失败保留旧收藏，登录失效时由用户主动打开扫码窗口。首页仍只读取已绑定的来源，不扫描全部笔记。
- 左下齿轮 → 外观 → 页面模式：**黑夜模式**沿用原深色金属，**白昼模式**在压低亮度的基础上适度提亮为中性银白金属，强化宽幅反光、细拉丝、加工边缘和深色文字，不带蓝调；**跟随系统**随系统应用主题实时切换白昼／黑夜。原生标题区、导航、各模块、弹窗及配置页同步适配，封面图不反色。
- 模式保存在本机私人目录的 `appearance.json`，下次启动继续使用；默认黑夜，显式白昼／黑夜不受系统变化影响；只有选「跟随系统」才响应系统应用主题，不修改Windows设置。启动在样式加载前解析主题，原生标题栏和配置页同步适配。未公开上传私人外观配置。
- 隔离窗口验证：`pwsh -NoProfile -File scripts/native_smoke.ps1 -Scope shell`，只使用合成数据且禁用真实抖音联网刷新；真实收藏同步另行验证。

## Windows 安装版

到仓库 **Releases** 下载 `Workdesk-Setup-版本-x64.exe`，按提示选择安装目录。当前仅验证 Windows x64；macOS 是后续计划，不是已完成支持。

- 安装包包含 Electron、Python、Chromium 及主要转写依赖；不需要在新电脑另装 Python、FFmpeg 或原有知识库 Skill。
- **仍需自己安装并登录 Codex CLI、安装 Obsidian、准备知识库。** AI 分析使用本机已登录的 Codex，模型可用性和额度取决于自己的账户；不包含 Plus 会员或任何 API Key。
- 首次启动选择知识库和外部程序路径；知识库须含 `处理文件/`、`原始资料/`，归类候选来自现有 `_索引.md`，软件不擅自创建新主题。
- 抖音首次使用需要扫码。有效登录之后，刷新和登录检查在后台进行；需要重新认证时才打开扫码窗口。
- 首次处理视频会在本机下载 PyAV 解码组件和 ASR 模型权重，需联网并留出空间。PyAV 固定版本来自官方 PyPI，不放入公共安装包；图文处理不需要这一步。模型默认使用官方来源，镜像可选但属于第三方。
- 关闭窗口会收进托盘，后台任务继续。托盘菜单可打开、修改配置，或在任务完成后彻底退出。
- 安装包暂未代码签名。请仅从本仓库 Releases 获取，并核对同版本 SHA256 文件；Windows 可能提示未知发布者。

### 数据边界

| 内容 | 位置与行为 |
|---|---|
| 程序 | 安装目录，可在更新时替换 |
| 收藏、队列、日志、登录状态、配置 | 本机 `%APPDATA%\workdesk`；不进仓库、安装包或 Release |
| 视频/原图和权重缓存 | 本机私人运行目录；素材也可选择知识库外的目录 |
| 笔记 | 用户选择的知识库 |

可选的私人标识只读取本机数据目录 `brand/mark.png`（界面）和 `brand/icon.png`（窗口/托盘）。仅接受固定文件名、PNG、最大 2MiB、边长最大1024px；缺失或不合规格时使用通用 W。没有上传入口、不接受任意路径或 SVG 脚本。私人标识不随源码或公共安装包分发；使用者需另行确认相关权利。

卸载默认保留本机私人数据。**换电脑安装不会自动搬运收藏、素材、知识库或登录状态**；知识库可自行同步，登录需重新认证。旧版迁移工具只复制队列数据库并保留源数据，不复制凭证，迁移后队列暂停。

视频和图文会发给本机 Codex 所连接的 AI 服务进行分析，这不是全程离线软件。只处理自己有权访问和使用的内容；抽样画面不等于完整审阅，笔记会保留证据与不确定项。

## 开发与更新

```powershell
npm ci
python scripts/prepare_runtime.py
npm test
npm run package:win
```

Windows 构建需 PowerShell 7、Node.js 22+ 和用于引导构建的 Python；`prepare_runtime.py` 从官方 CPython 包构建独立运行环境，验证官方 SHA512，并安装固定版本依赖。不要复制自己的 venv、浏览器 Profile 或 Codex 配置进项目。

完整运行时准备完后，可运行隔离的真实窗口检查：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\native_smoke.ps1
```

测试启动器只使用 `build/native-test` 合成数据目录，等待窗口检查结束并将日志落盘。不要直接用 `& electron.exe` 启动 GUI 测试后结束命令窗口：输出管道可能提前关闭。测试日志遇到 EPIPE 仍保存在本机文件，其他异常和断言失败仍返回失败。

项目代码与私人数据严格分离；源文件和安装载荷采用白名单。**日常修改只在本机验证；有阶段性成果时先向用户确认，得到本次确认后才测试 → 隐私检查 → 提交/推送。正式发布另确认版本和安装包。** 确认后可运行 `pwsh -NoProfile -File scripts/sync.ps1 -Message "更新说明" -ConfirmUpload`；不设置自动上传后台任务。

`docs/github-actions/` 保留自动测试与 Windows Release 模板。当前发布凭证没有 `workflow` 权限，因此模板未启用；日常同步和正式发布仍先在本机完成测试与隐私检查。未来授权后才能把模板放入 `.github/workflows/`，不能把模板当成已运行的 CI。
